## Key Techniques

- (1x) Using agentic search to explore and understand codebases without indexing.
- (1x) Leveraging terminal commands and Vim-like workflows for code editing.
- (1x) Employing Cloud Code as a 'thought partner' to brainstorm implementation strategies before writing code.
- (1x) Avoid automated Rolf loops, maintain manual control
- (1x) Use plan mode to review and edit AI-generated plans
- (1x) Create custom agents (e.g., Docs Explorer agent) for specialized tasks
- (1x) Implement project-specific skills to guide AI behavior
- (1x) Prioritize explicit instructions over implicit assumptions
- (1x) Leverage context engineering for better prompt clarity
- (1x) 7-phase workflow: brainstorming → Git worktree isolation → planning → sub-agent development → TDD → code review → branch completion
- (1x) 14 automated skills for design validation, test-first development, and code review
- (1x) Visual Companion for browser-based layout comparisons and interactive design feedback
- (1x) Test-driven development with the Iron Law (no production code without failing tests)
- (1x) Sub-agent parallel execution for task decomposition
- (1x) Use pre-tool use hooks to block or redirect CLI commands
- (1x) Convert CLAUDE.md instructions into deterministic hooks
- (1x) Create bash scripts to enforce command rules
- (1x) Leverage settings.json to register hooks
- (1x) Test hooks by triggering blocked commands
- (1x) Using plan mode to generate clarifying questions and explore codebases
