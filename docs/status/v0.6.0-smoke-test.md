## Issues found

### Issue #1 — Slash commands not registered after restart

`/scribe-status` and `/xref-lint` not recognized as slash commands after Claude Code restart and plugin pin update. Shows `Unknown command: /scribe-status`.

**Root cause hypothesis:** plugin command registration cache stale, requires `/plugin reload` or full client restart with cache wipe.

**Severity:** medium — workaround = invoke skill body manually, or use natural language triggers.

**Filed for:** v0.6.1 patch.

### Issue #2 — Skill name disambiguation

When agent invokes `Skill` tool with `project-scribe:scribe`, it routes to the existing `scribe` (STATE.md dashboard) skill, not the new `scribe-status` skill. Both live under `project-scribe:` namespace.

**Severity:** low — `scribe-status` and `scribe` are different skills with clear different descriptions, but tool router defaulted to `scribe` on the keyword.

**Workaround:** Skill descriptions are correct; this may auto-resolve once clients fully reload. Re-test after `/plugin reload`.

**Filed for:** v0.6.1 to either:
- Rename `scribe-status` → `scribe-health` (less collision risk), OR
- Document that `scribe-status` requires explicit slash invocation.
