## Issues found

### Issue #1 — Slash commands require namespace prefix (RESOLVED)

`/scribe-status`, `/xref-lint`, `/compact-decisions` all returned `Unknown command` after restart. Root cause: Anthropic plugin slash commands need full namespace prefix `/<plugin>:<command>`, e.g. `/project-scribe:scribe-status`. Bare `/scribe-status` only resolves if it's a top-level command not namespaced under a plugin.

**Resolution:** No code bug. Documentation gap. v0.6.1 should update README to show namespace-prefixed invocation.

**Verified working:**
- `/project-scribe:scribe-status` ✓
- (other plugin commands same pattern — `/project-scribe:xref-lint`, `/project-scribe:compact-decisions`, `/project-scribe:scribe`)

**Severity:** none (UX docs gap). v0.6.1 README patch.

### Issue #2 — (RESCINDED, was misdiagnosis)

Previously claimed naming collision between `scribe-status` and `scribe`. Reanalysis: `scribe.md` is a slash command (dashboard), `scribe-status` is a slash command + skill (new in v0.6.0). They are correctly distinct. No bug.
