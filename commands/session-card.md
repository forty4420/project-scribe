---
description: Generate a shareable session-card — one self-contained markdown block summarizing the current scribe-enabled project's state, decisions, recent activity, and memory health. Paste-ready for Twitter, Reddit, Discord, or screenshot.
---

Invoke the `session-card` skill.

The skill will:
1. Bail silent if `docs/STATE.md` is missing (project not scribe-enabled).
2. Read STATE.md current focus, last shipped, next up, deferred count.
3. Read DECISIONS.md count + most-recent entry.
4. Read git log from the last 7 days for commit count + top 3 commit subjects.
5. Read memory dir to bucket files into load-bearing / active / idle.
6. Read `.bump-log` mtime for last-hook-fire freshness.
7. Compose a single fenced markdown card, ≤ 60 lines, with emojis as section dividers and a `— Generated by project-scribe` footer linking back to the repo.

Read-only. No edits, no network calls, no PII (commit author names excluded). Card is emitted to chat — user decides whether to copy, paste, screenshot, or save.

Optional: pass `--png` to get a prompt for the `nano-banana-pro` plugin (if installed) to render the card as a 1200x630 social-card image. Default is markdown-only.
